Dúvidas

Perguntas frequentes

A prévia é mesmo grátis?

Sim. Você vê o novo design completo antes de pagar qualquer coisa.

Vocês inventam informações sobre a minha empresa?

Não. Usamos apenas os textos, fotos e contatos que já estão no seu site. Podemos reescrever os textos para ficarem mais claros, mantendo os fatos.

Como publico o site depois de comprar?

Você recebe um arquivo .zip. Basta enviar a pasta para a sua hospedagem atual ou arrastá-la para um serviço gratuito como o Netlify Drop. As instruções vão junto.

Funciona com qualquer site?

Funciona com a maioria dos sites institucionais, de serviços e de pequenas empresas. Lojas virtuais completas e sistemas com login não são recriados, mas podemos destacar os links para eles.

Posso editar o site depois?

Sim. O código é seu. Qualquer pessoa que saiba HTML consegue editar, e os textos podem ser trocados num editor de texto comum.
